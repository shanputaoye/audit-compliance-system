# 项目验收审计智能合规管理系统

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Status](https://img.shields.io/badge/status-prototype-orange.svg)]()

> 面向国有企业技改/科研/信息化项目的验收审计合规管理工具，覆盖指标闭环验证 + 材料合规清单 + 组织架构 + AI 智能辅助，帮助计划处/固投处确保审计进场前资料齐全、证据完整、追溯清晰。

## 为什么需要这个工具？

### 痛点

国企技改项目验收审计中，计划处/固投处面临的核心挑战：

1. **资料散落各处，不知缺什么** — 一个项目的 20+ 项验收资料分散在档案室、使用部门、财务处手中，手工对清单易遗漏
2. **指标是否达标，说不清楚** — 可研承诺的技术指标，验收时如何逐项证明已实现？审计要看完整的证据链
3. **变更管理混乱，审计必查** — 工程变更、设备调整的审批流程和资料最容易出问题
4. **问题整改是否闭环，记不住** — 历次审计发现的问题，哪些已整改、证据是否充分，手工跟踪易遗忘
5. **审计报告拼凑耗时** — 验收前跨部门收集数据，手工编制整套验收总结报告耗时数天
6. **多项目同时推进，顾此失彼** — 一个部门通常管理 5-15 个在建项目，Excel 管理极易混淆

### 目标用户

- **计划处/固投处/技保处** — 项目验收审计的第一责任部门
- **项目使用部门** — 设备验收、技术指标验证的执行方
- **审计处/第三方审计** — 合规审查方

### 竞品空白

| 竞品类别 | 为什么不行 |
|----------|-----------|
| 项目管理软件 (Project/禅道) | 管进度不管指标闭环，没有审计报告 |
| 审计软件 (用友/鼎信诺) | 查财务账为主，不管技术指标符合性 |
| 档案管理软件 | 管文件归档，不管"指标→证据"的逻辑映射 |
| Excel 手工 | 效率低、易出错、不可追溯、无法协作 |

**本产品是唯一聚焦"指标闭环 + 审计材料合规"的专用工具。**

## 核心功能

### 1. 数据源管理（交付物）

以招标文件、合同、技术协议等交付物为数据源头，按责任人分组管理：

- 支持导入招标文件、合同、技术协议、交付物等多类文档
- **强制指定责任人**，交付物归到具体人名下
- 版本管理与变更历史追溯
- 交付物与指标/材料双向关联，定稿后驱动对应验收闭环

### 2. 技术指标闭环验证（五阶段模型）

面向项目用户（设备验收方），追踪技术指标从需求到闭环的全生命周期：

```
需求定义 → 方案设计 → 实施执行 → 验收验证 → 闭环确认
```

- 每个阶段支持工作流状态：草稿 → 提交审核 → 通过 / 驳回（含驳回原因）
- 完整版本历史，每次变更记录操作人、日期、内容
- 操作人 / 审核人 / 评审意见 / 专家意见 / 意见闭环 全链路管理
- 断点自动定位，驳回项高亮提醒

### 3. 审计材料合规清单（七大类）

面向计划处（审计合规方），按项目类型预设多套验收材料清单：

| 类别 | 典型材料 |
|------|---------|
| 一、立项审批类 | 项目建议书批复、可研报告批复、初设概算批复 |
| 二、招标采购类 | 招标方案备案、招标/评标文件、中标通知书 |
| 三、实施过程类 | 施工组织设计、监理报告、变更审批文件 |
| 四、设备验收类 | 设备到货清单、试车报告、技术指标验证报告 |
| 五、财务审计类 | 竣工结算、财务决算、第三方审计报告 |
| 六、专项验收类 | 环保、消防、安全、职业卫生、档案验收 |
| 七、综合验收类 | 验收申请、验收总结、问题整改闭环 |

- 每份材料可标注审计规则依据
- 会议记录 + 专家意见 + 电子签名状态管理
- 工作流：编制中 → 提交审核 → 定稿 / 退回修订

### 4. AI 智能助手（常驻右侧面板）

页面感知的 AI 助手，根据当前页面自动切换功能：

| 当前页面 | AI 功能 |
|---------|--------|
| 仪表盘 | 项目健康度分析 |
| 数据源中心 | **文档解析器**：提取关联指标、建议补充关联 |
| 指标闭环 | **智能检查** + 闭环建议 + **依据文件决策参数状态** |
| 材料清单 | 合规检查 + 定稿率目标分析 |
| 审核中心 | 审核队列 + 优先级建议 |
| 页面交互 | **点击任意指标/材料行** → AI 自动深度分析 + 推送通知 |

### 5. 组织架构管理

- 部门管理：正常 / 已撤销 / 已更名 + 变更历史
- 人员管理：在职 / 已离职 + 部门归属 + 角色
- 所有责任人从组织人员库下拉选择
- 离职人员名下交付物自动风险提示

### 6. 项目模板定制

4 套预置模板，每种模板有独立的模块结构、材料清单、交付物、里程碑：

| 模板 | 材料分类 | 默认指标 | 适用场景 |
|------|---------|---------|---------|
| 技改项目 | 7 类 | 4 项 | 固定资产投资项目 |
| 科研项目 | 4 类 | 2 项 | 科研课题验收 |
| 信息化项目 | 4 类 | 2 项 | 信息系统建设验收 |
| 能力建设项目 | 一次性 | 4 项 | 能力评估项目 |

### 7. 审计报告一键生成

基于项目实际数据自动生成结构化审计报告，包含：交付物概览、指标完成统计、材料定稿率、驳回明细、逾期清单、专家意见闭环情况。

## 产品价值

### 效率提升

- 审计报告生成：从半天至几天 → **几分钟**
- 指标状态检查：手工逐条对比 → **一键批量扫描**
- 材料缺失定位：人工排查 → **仪表盘实时可见**

### 风险降低

- 杜绝指标验收遗漏（五阶段闭环自动判定）
- 退回材料及时提醒（逾期/驳回/断点三色预警）
- 离职人员名下交付物风险提示

### 合规保障

- 每份材料标注审计规则依据
- 完整操作日志和版本历史
- 责任人变更可追溯

## 技术架构

```
浏览器                 Flask REST API           SQLite
───────               ──────────────          ──────
HTML5/CSS3/JS   ←→   Python 3.8+Flask  ←→   audit.db
(Bootstrap 3)         + python-docx            (本地存储)
                      + PyInstaller打包
```

- **兼容 Windows 7** — Python 3.8 + ES5 JavaScript + Bootstrap 3
- **单机即用** — 无需安装数据库或 Web 服务器，双击 .exe 启动
- **全离线运行** — 数据本地存储，不上传云端
- **支持局域网协作** — WAL 模式支持多人并发访问

## 快速开始

### 方式一：直接使用（HTML 原型）

1. 双击打开 `技改验收审计合规助手.html`
2. 数据保存在浏览器 localStorage
3. 适用于快速演示和功能验证

### 方式二：完整部署（开发中）

```bash
# 安装依赖
pip install flask python-docx waitress

# 启动服务
python app.py

# 打开浏览器
# http://localhost:8899
```

### 方式三：打包为 .exe

```bash
pyinstaller --onedir --add-data "static;static" app.py
# 输出：dist/app/app.exe
```
