## 核心功能

### 1. 项目创建向导（6步）

| 步骤 | 内容 | 说明 |
|------|------|------|
| 1 | 项目信息 | 名称/类型/日期 |
| 2 | 组织架构 | 勾选部门+人员 |
| 3 | 指标模块 | 激活模块并自定义验收指标 |
| 4 | 材料清单 | 按分类添加审计材料 |
| 5 | 里程碑 | 配置节点和计划日期 |
| 6 | 确认创建 | 预览全部配置，一键建项 |

### 2. 技术指标闭环验证

五阶段追踪：需求定义 → 方案设计 → 实施执行 → 验收验证 → 闭环确认

- 每阶段含完整的审批工作流（草稿→提交→审核→通过/驳回）
- 驳回强制填写原因，版本号自动递增
- 支持专家评审意见和意见闭环

### 3. 审计材料合规管理

7 大材料分类：立项审批 / 招标采购 / 实施过程 / 设备验收 / 财务审计 / 专项验收 / 综合验收

- 完整工作流：编制中 → 提交审核 → 审核通过（定稿）/ 退回修订
- 支持会议记录和专家电子签名
- 自动检测逾期材料并预警

### 4. 数据源中心（交付物管理）

- 招标文件/合同/技术协议等交付物的导入和版本管理
- 按责任人分组展示
- 交付物与指标/材料双向关联
- 定稿后可驱动关联指标的闭环推进

### 5. 里程碑甘特图

- 彩色条形图展示节点进度（已完成/进行中/逾期/待启动）
- 红色今日线标注当前位置
- 逾期节点自动计算天数并预警

### 6. AI 智能助手（页面感知）

| 页面 | AI 功能 |
|------|---------|
| 仪表盘 | 项目健康度分析 |
| 数据源中心 | 文档解析 + 关联指标提取 |
| 指标闭环 | 指标状态检查 + 闭环建议 + 依据文件决策 |
| 材料清单 | 合规检查 + 定稿率目标分析 |
| 组织架构 | 人员工作量分析 + 组织风险检查 |
| 审核中心 | 批量审核建议 + 驳回项风险评估（支持点击深度分析） |
| 进度节点 | 逾期影响分析 + 关键路径建议 |
| 审计报告 | 报告预览 |

### 7. 审计报告自动生成

5 大章节：项目概况 → 技术指标闭环验证 → 审计材料合规检查 → 里程碑进度 → 风险提示与整改建议

### 8. 组织架构管理

- 部门/人员双类型管理
- 支持状态变更：正常/已撤销/已更名/离职
- 完整变更历史追溯
- 离职人员名下交付物自动风险提示

### 9. 审核中心

- 集中展示所有待审核/需重做材料
- 点击任意行触发 AI 深度分析（审核状态/链路/责任人/关联指标/建议）
- 一键通过/退回，支持退回原因必填

### 10. 4 套项目模板

| 模板 | 特色 |
|------|------|
| 技改项目 | 8模块/7类材料/10里程碑 |
| 科研项目 | 6模块/4类材料/6里程碑 |
| 信息化项目 | 6模块/4类材料/6里程碑 |
| 能力建设项目 | 5模块/5类材料/5里程碑 |

## 技术架构

```
单文件 HTML（~140KB）
├── CSS（内联）
│   ├── CSS 变量主题系统
│   ├── 侧边栏/顶栏/内容区/弹窗/AI面板布局
│   └── 响应式媒体查询
├── HTML
│   ├── 导航侧边栏（9个视图入口）
│   ├── 10个视图面板
│   └── 8个功能弹窗 + 1个向导弹窗
└── JavaScript（~1000行）
    ├── 模板定义（4种项目类型）
    ├── 数据模型（D对象：projects[] → org/deliverables/indicators/materials/milestones）
    ├── 存储层（localStorage + JSON 导入/导出）
    ├── 导航系统（showV/refresh/updateB）
    ├── 10个视图渲染函数
    ├── 6个CRUD模块（交付物/指标/阶段/材料/组织/里程碑）
    ├── AI面板引擎（页面感知 + 12个分析函数 + 点击交互）
    ├── 项目创建向导（6步 + data-*安全事件处理）
    └── 审计报告生成器（5大章节模板）
```

## 设计原则

- **零依赖**：纯 HTML/CSS/JS，无框架，无构建工具
- **离线可用**：localStorage 持久化，无服务端依赖
- **单文件分发**：一份 `.html` 即可完整运行
- **中英文标识变量**：代码注释使用中文，变量名使用英文
- **安全的事件处理**：所有动态 HTML 中的 onclick/onchange 使用 `data-*` 属性传参，消除引号注入风险
